## タスク

**0 から Blender ベースの自動着せ替えパイプラインを構築してください。**

---

## 要件

### ゴール

pokekuro 3D アバター（`koba.glb`）に対して、服単体（`cloth.glb`）を自動でフィットさせる。

**使用シーン:** アプリ側で複数の服を切り替えて着用できるようにする。

```
[オフライン] 服ごとに 1 回実行:  cloth.glb → パイプライン → fitted.glb（保存）
[アプリ内]   アバター + fitted.glb を読み込み、服を切り替え表示
```

### アバター仕様

- `koba.glb` — pokekuro キャラクター
- **ポーズ:** 完全 T ポーズ（腕＝真横 X 軸）
- **スケール:** メートル単位

### 入力ファイル

| ファイル | 用途 |
|---|---|
| `koba.glb` | アバター体 |
| `cloth.glb` | 服（生のメッシュ） |
| `pic.png` | 入力画像（Meshy 生成用） |

### 出力ファイル

| ファイル | 用途 |
|---|---|
| `output/fitted.glb` | **最終出力** — アプリで読み込む |
| `output/cloth_fitted.glb` | （オプション — 中間ファイル） |
| `output/render/*.png` | 検証用レンダリング（複数アングル + 接写） |

---

## 制約（厳守）

1. **長さを変えるな** — 服の袖・裾の長さは元のまま
2. **ぶかぶかで OK** — 体にピッタリ張り付けない。適度な隙間を保つ
3. **貫通をなくす** — 手首・袖が体を突き抜けない
4. **シンプルに** — 不要な処理（物理シミュレーション、細分化、多重スムージング）は入れない
5. **最小処理** — アルゴリズムは可能な限りシンプル

## パイプライン設計指針

### 処理の流れ（例）

```
入力: koba.glb, cloth.glb
  ↓
1. インポート・メッシュ統合
  ↓
2. スケール・位置合わせ
  ↓
3. メッシュ補正（オプション）
  ↓
4. 貫通除去処理
  ↓
5. エクスポート
  ↓
出力: fitted.glb
```

### 考慮すべき問題

| 問題 | 対策の考え方 |
|---|---|
| **スケーリング** | アバターと服のサイズが異なる → どの寸法で合わせるか（幅？高さ？） |
| **位置合わせ** | 服を体のどこに配置するか（胴体中央？肩？） |
| **貫通** | 服の頂点が体の内側に入っている → 体の表面に押し出す方法は？ |
| **形状保持** | 処理時に服の形（袖のチューブ形、裾など）を損なわない → どの手法で？ |
| **ポーズ不一致** | アバターと服のポーズが異なる場合 → 検出・補正方法は？ |
